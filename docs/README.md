# PSexp 文档索引

本文档目录面向普通用户、介绍机器人和开源维护者。源码路径以仓库根目录为基准；作者本机的 `PSexp/源码/` 就是这个仓库根目录。

| 文档 | 适合谁 | 内容 |
| --- | --- | --- |
| [功能说明书](功能说明书.md) | 用户、AI、维护者 | 各项功能的用途、操作、原理、示例玩法、边界、脚本、配置、回执、日志与排错 |
| [AI 导览与问答](AI导览与问答.md) | 介绍机器人、客服助手、内容作者 | 功能检索编号、讲解示例、54 个常见问答、易误导表述与知识库分块规则 |
| [更新安全与发布签名](更新安全与发布签名.md) | 用户、发布维护者 | 开源与私钥边界、强制验签协议、服务器只读隔离、换机与首次升级 |
| [开发指南](开发指南.md) | 开发者 | 构建、自测、模块、导出链与维护要求 |
| [UI 规范](UI规范.md) | 界面设计与开发者 | 组件尺寸、连续曲率、颜色、状态、布局和动效约定 |

初次了解产品先读功能说明书的第 01–03 节，再按需要看具体功能。机器人接入先读 AI 导览的版本规则，再检索主手册，不能仅凭简短功能名扩展承诺。

功能手册目前对应 2026-10-30 的工作区源码，包含尚未发布的修改；已下载 EXE 的实际能力应以对应版本和构建来源为准。本轮文档编写只核对源码，没有编译或实机验证。
