# PSexp

用于 Photoshop 的 Windows 批量导出工具，支持将整张画布、画板、图层和原生切片导出为 JPG / PNG。

使用 C#、.NET 10 和 Avalonia 构建，以 [MIT 许可证](LICENSE)开源。

下文功能说明对应 main 分支源码，发布包功能以对应版本为准。

## 功能

- 四类功能：快速导出整张画布、画板导出（全部 / 选中）、图层导出（一级图层 / 图层，图层模式可选选中或全部）和原生切片导出。
- JPG / PNG 格式和质量调节，输出位置可选文档所在目录、桌面或自定义路径。
- 切片可填写子文件夹名集中保存，留空直接输出；所有用户参数与功能偏好自动记忆，清空也会保存。
- 显示导出任务状态、输出数量和错误信息。
- 浅色 / 深色主题、窗口置顶、贴边收纳，以及分类卡片式设置界面。
- 托盘后台常驻，右键菜单提供显示窗口、快速导出、目录入口、置顶、设置、检查更新和退出。
- 自动检测和后台下载更新，校验完成后手动确认重启安装。

| 功能 | 输出范围 |
| --- | --- |
| 快速导出 | 当前画布的完整可见合成效果，一张图片，保留画布尺寸 |
| 画板导出 | 全部或选中的画板，每个画板一张图片 |
| 一级图层 | 以整张画布为基底，逐个最外层图层/组与有效可见公共内容合成；组不拆子层 |
| 图层 · 选中图层 | 导出 Photoshop 当前选择，选中的图层组整体输出；组与其子层同时选中时只输出组 |
| 图层 · 全部图层 | 递归导出组内的非组图层，不重复输出图层组 |
| 切片导出 | Photoshop 原生用户切片及基于图层的切片，按切片边界输出 |

一级图层可用于多方案套图：各方案作为普通顶层组，可见的排除水印/边框放在上方，公共底图放在下方，逐个输出完整画布合成。名称以“排除”开头的图层或组及其子层不独立导出；显示的排除项保留显示，隐藏项保持隐藏，实际呈现受父组和叠放关系影响。真正背景按 `isBackgroundLayer` 判断，无需排除前缀，同样保留初始可见性且不独立输出；普通名为“背景”的层不自动享有这个规则。其他符合条件的隐藏主体仍会导出；结束后尽力恢复可见性。详见 [图层合成、玩法与源码依据](docs/功能说明书.md#layers)。

切片导出的范围对应“存储为 Web 所用格式”中的用户切片。按从上到下、从左到右排序，以“文件前缀_切片名”或“文件前缀_序号”命名；忽略自动补齐切片及非图像切片。格式和质量使用本工具当前参数，不复用 Photoshop 给每片设置的优化参数，不生成 HTML。整批只建立一个临时合成副本，逐片裁剪、保存并恢复完整画布，结束时关闭一次，避免每片反复开关文档。不修改原文档，也不会为导出擅自缩小整张画布。

## 下载与运行

前往 [Releases](https://github.com/linhuoxi/PSexp/releases) 查看已发布版本和 Windows x64 附件；若没有附件，可按下方说明自行编译。

1. 使用 Windows x64，安装并启动 Photoshop，打开需要导出的文档。
2. 运行 PSexp，选择导出模式、格式及输出目录。
3. 执行导出并检查任务状态和生成的图片。

选择文档位置时，文档需先保存；实际输出目录显示在选项下方。只有自定义位置展开路径输入框，切换预设会保留填写的路径。

默认关闭窗口后收起到托盘，导出任务继续运行；单击托盘图标恢复主窗，右键菜单可退出。在“常规 → 窗口”中可关闭常驻。

默认发布版不包含 .NET 运行时，运行前请安装 **.NET 10 x64 Runtime**（普通运行时即可，无需安装 SDK）。导出依赖 Photoshop UXP 独立脚本支持（Photoshop 23.5+）以及本机可用的 `.psjs` 文件关联；文档探测使用 Windows COM。不同 Photoshop 版本的实际兼容性需要实机验证。

取消任务表示 PSexp 停止等待，Photoshop 可能仍在执行已触发的操作。再次导出前请确认 Photoshop 已结束上一任务。

## 检查与安装更新

设置页“更新”支持手动检查；默认在启动后及每 6 小时自动检测，并在后台下载。当前源码先使用内嵌公钥验证清单签名，再校验文件大小、SHA256 和内置版本；通过后，点击“重启并更新”完成替换，导出期间禁止安装。可关闭自动检测或后台下载。

安装过程写入 EXE 同级 `psx.log`，保留旧 EXE 备份并在失败时尝试回滚。默认发布版需要 .NET 10 x64 Runtime。目录开发版使用编译脚本更新，自动安装仅支持单文件发布版。

源码、签名协议和公钥均公开，私钥留在发布者本机，不进入应用、GitHub 或服务器。新保护需要编译进新版 EXE，旧版不会远程获得验签能力；签名与服务器隔离细则见 [更新安全与发布签名](docs/更新安全与发布签名.md)。

## 从源码编译

需要 **.NET 10 SDK**。在克隆后的仓库根目录运行：

```powershell
.\编译.bat
```

脚本先运行 .NET 自测，再发布不包含 .NET 运行时的 Windows x64 单文件程序；成功后将 `PSexp v3.0.exe` 放到 `编译.bat` 旁边，中间文件保存在系统临时目录。默认不混淆、不裁剪，保留单文件压缩；脚本不上传 GitHub。

生成的 EXE 不纳入 Git 版本管理。Node.js 仅用于额外的 UXP 脚本行为测试，运行软件不需要 Node.js。

## 项目结构

```text
PSdodo/                         应用源码、界面和内置 Photoshop 脚本
tests/PSdodo.Tests/             .NET 自测和 UXP 脚本行为测试
references/photoshop-scripts/   历史脚本参考，不直接编译进应用
docs/                          开发和界面规范
编译.bat                        公开的编译与自测入口
LICENSE                         MIT 许可证
```

GitHub 仓库根目录对应作者本地的 `PSexp/源码/`，克隆后无需再创建一层 `源码`。
